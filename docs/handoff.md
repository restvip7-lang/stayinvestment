# Памятка для новой сессии Claude

Коротко о том, что сделано и как устроена работа. История переписки в новую сессию не переносится — этот файл её заменяет.

## Что это
Новый сайт Stay Investment: Astro 7 + Tailwind 4, SSR. Языки: ru (без префикса), en, sr, tr. Подробности — в [README.md](../README.md).

## Где что лежит
- **Черновой репозиторий:** `restvip7-lang/stayinvestment`, ветка `claude/practical-shannon-z1pifq` — сюда идут все правки; из неё собирается тестовая копия https://stayinvestment.vercel.app.
- **Рабочий репозиторий:** `stayproperty-org/stayinvestment`, ветки `dev` и `main`. У облачной сессии доступа к нему нет.
- **Сервер:** https://new.stayinvestment.com — Plesk 167.86.66.155, папка `~/stayinvestment-app`, Node.js 24 в `~/node24`, сайт обычным процессом на 127.0.0.1:4330, Apache пересылает запросы (`.htaccess`), cron раз в минуту забирает `main` рабочего репозитория. Описание — [deploy/README.md](../deploy/README.md), раздел «Без администратора». Старый WordPress на stayinvestment.com не трогаем.

## Как правка попадает на сервер
1. Claude коммитит и пушит в черновую ветку, проверяет сборку на Vercel.
2. Владелец на ноутбуке запускает `push-to-work.bat` (лежит в `deploy/`): он отправляет версию в `dev` и открывает страницу запроса `dev` → `main`.
3. Владелец сливает запрос (Create a merge commit; ветку `dev` не удалять).
4. Через 1–2 минуты сервер обновляется; проверка — `https://new.stayinvestment.com/version.txt` (номер коммита `main`).

Правила: в рабочий репозиторий — только по команде владельца и без force; на сервер ничего не выкладывать и не менять без отдельного подтверждения; пароли, ключи и токены в чат не просить и не принимать.

## Незаконченное
- **API «Портфолио»** (объекты каталога): адрес `https://adminer.stayproperty.com/ws`, вход — ключ клиента + логин и пароль (переменные среды `STAY_TOKEN`, `STAY_USERNAME`, `STAY_PASSWORD`). Скрипт пробы — `npm run portfolio-sample`. В прошлой сессии сервер отвечал `401 Unauthorized`: сессия видела старые значения переменных. Первым делом запустить скрипт. Если доступ есть — сверить объекты с пакетами (таксономия `package_type`, id 11) и решить с владельцем, где хранить инвестиционные показатели (взнос, рассрочка, доходность): в старом API их не было. Сейчас каталог — 48 файлов в `src/content/objects`.
- **Заявки с форм** только пишутся в журнал: нужен адрес для `LEAD_WEBHOOK_URL`.
- **Турецкий перевод** машинный, без вычитки носителем.
- **Перенос основного домена** и открытие для поисковиков (`STAY_NOINDEX=0`) — отдельным решением владельца.
