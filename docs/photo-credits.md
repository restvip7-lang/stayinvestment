# Фото из открытых источников

Фото городов на странице «Контакты» (для офисов, у которых нет своего снимка) взяты с Wikimedia Commons.
Все три опубликованы под лицензией **CC0** (общественное достояние): можно использовать в коммерческих целях,
указывать автора не обязательно. Источники записаны здесь, чтобы происхождение каждого файла можно было проверить.

| Файл | Что на фото | Автор | Источник |
|---|---|---|---|
| `public/images/offices/cyprus.jpg` | Старая гавань Гирне (Кирения), Северный Кипр | August Dominus | https://commons.wikimedia.org/wiki/File:Kyrenia_ljeti.jpg |
| `public/images/offices/dubai.jpg` | Бизнес-Бэй и Бурдж-Халифа, Дубай | Robert Bock | https://commons.wikimedia.org/wiki/File:Dubai_skyline_unsplash.jpg |
| `public/images/offices/london.jpg` | Тауэрский мост на рассвете, Лондон | Pierre Blaché | https://commons.wikimedia.org/wiki/File:Tower_Bridge,_London_at_sunrise.jpg |

Когда появятся фото самих офисов — заменить файлы в `public/images/offices/`, убрать `cityPhoto` в `src/lib/offices.ts`
и выполнить `npm run optimize-images`.
